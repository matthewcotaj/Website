Magnetic Ordering, by Monte Carlo

The classical Heisenberg ferromagnet on a 3D cubic lattice, run with Metropolis Monte Carlo in your browser. Cool it through the Curie temperature and watch it order, then run the full temperature sweep to pin down Tc.

My thesis work on EuGdCuS3 nanorods was about how Gd3+ substitution changes magnetic ordering, from the synthesis and characterization side. This is the finite-temperature theory side of the same physics, on a model system simple enough to simulate from scratch. Python source on GitHub →

|M| / N vs. Monte Carlo sweep

Each site holds a unit-vector spin coupled to its six nearest neighbors, H = −J Σ si·sj, with periodic boundaries. One sweep is N Metropolis proposals: pick a random site, propose a completely random new orientation, and accept it with probability min(1, e−ΔE/T).

The literature Tc for this model is 1.443 J/kB, and it scales with J, so T/Tc above uses 1.443 J. Above it, |M|/N sits near its finite-size floor (about 1/√N for random spins). Below it the lattice picks a direction spontaneously; the gold arrow in the 3D view shows which one. Try Randomize at T = 0.3 to watch a quench relax, or sit right at Tc to see the large, slow fluctuations of a critical point.

Same procedure as main.py: each lattice starts random and anneals from high to low T, with equilibration sweeps at each temperature before sampling E and |M| every sweep. Each lattice size runs in its own background thread, so the page stays responsive.

χ = (⟨M²⟩ − ⟨|M|⟩²) / NT peaks at the transition, and the peak grows and sharpens with L: the finite-size signature of a real phase transition. On these small lattices the peak sits a little above the infinite-lattice value (about 1.50 vs. 1.443). C = (⟨E²⟩ − ⟨E⟩²) / NT² shows the energy side of the same transition. The Binder cumulant UL = 1 − ⟨M⁴⟩ / 3⟨M²⟩² is size-independent at Tc, so the curves for different L should cross there; at quick-run statistics that crossing is noisy, so it is a secondary check. Above Tc, 1/χ is fit to the Curie–Weiss law (T − θ)/C over T > 1.3 Tc.
